## 6. How to Load and Verify in Cisco Packet Tracer (Student Quick-Guide)

If you are demonstrating this live or taking screenshots for submission:
1. **Launch Cisco Packet Tracer**.
2. **Add Devices**:
   - `1x` Cisco 3560 Switch (rename to `NetArchitect-DIST-01`)
   - `1x` Cisco 2960 Switch (rename to `NetArchitect-ACCESS-01`)
   - `1x` Cisco 2911 Router (rename to `NetArchitect-EDGE-01`)
3. **Cabling**:
   - Copper Straight-Through from `DIST Gi1/0/48` to `ACCESS Gi0/48`
   - Copper Straight-Through from `DIST Gi1/0/1` to `EDGE Gi0/0`
4. **Load Configurations**:
   - Click each device $\rightarrow$ **CLI** tab.
   - Enter configuration mode:
     ```text
     enable
     configure terminal
     ```
   - Copy the contents from `configs/campus-lan/layer3_switch.txt` (or replace `<SET_SECRET_SECURELY>` with `cisco123`).
   - Paste into the CLI window.
5. **Run Verification Commands**:
   - `show ip interface brief`
   - `show vlan brief`
   - `show interfaces trunk`
   - Capture a screenshot showing the topology with green link lights!
